TOP 10 MOST-USED METHODS
================================================================================

1. client.session.list()
   → List all sessions with optional filtering
   → Returns: SessionListResponses

2. client.session.create()
   → Create new session with optional agent/model defaults
   → Returns: SessionCreateResponses
   → Emits: session.created event

3. client.session.prompt()
   → Send prompt to session (streams SSE events)
   → Returns: ServerSentEventsResult<SessionPromptResponses>
   → Emits: session.next.* events (text, tool, reasoning, etc.)

4. client.session.command()
   → Send command to session (streams SSE events)
   → Returns: ServerSentEventsResult<SessionCommandResponses>
   → Emits: session.next.* events

5. client.session.get()
   → Get session details
   → Returns: SessionGetResponses

6. client.session.delete()
   → Delete session
   → Returns: SessionDeleteResponses
   → Emits: session.deleted event

7. client.session.message()
   → Get specific message
   → Returns: SessionMessageResponses

8. client.session.messages()
   → List messages in session
   → Returns: SessionMessagesResponses

9. client.permission.list()
   → List pending permission requests
   → Returns: PermissionListResponses

10. client.permission.reply()
    → Grant/deny permission
    → Returns: PermissionReplyResponses
    → Emits: permission.replied event

================================================================================
KNOWN LIMITATIONS (SDK v2)
================================================================================

1. No offline mode — SDK requires active server connection
2. No local caching — All data fetched from server
3. No session export — Can't export sessions to file
4. No custom metadata — Limited session metadata support
5. No batch operations — Must call methods individually
6. No webhooks — Only SSE for real-time updates
7. No rate limiting — Client must implement own throttling
8. No request cancellation — No built-in abort support
9. No streaming file uploads — File parts must be pre-uploaded
10. No session snapshots in v1 — SDK v2 only feature
